# pi-skill-codebase-design

[![Pi Package](https://img.shields.io/badge/pi--package-skill-blue)](https://github.com/IgorGuariroba/pi-skill-codebase-design)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

**codebase-design** skill for the **[Pi coding agent](https://pi.dev)**, adapted from Matt Pocock's Engineering Skills.

> Shared vocabulary for designing deep modules. Use when the user wants to design or improve a module's interface, find deepening opportunities, decide where a seam goes, make code more testable or AI-navigable, or when another skill needs the deep-module vocabulary.

---

## Installation

Install directly into Pi using `pi install`:

```bash
pi install git:github.com/IgorGuariroba/pi-skill-codebase-design
```

Or clone into your local/global skills directory:

```bash
# Global Pi skills directory:
git clone https://github.com/IgorGuariroba/pi-skill-codebase-design.git ~/.pi/agent/skills/codebase-design

# Or Agent Skills standard path:
git clone https://github.com/IgorGuariroba/pi-skill-codebase-design.git ~/.agents/skills/codebase-design
```

---

## Usage

Trigger it explicitly in your session:

```text
/skill:codebase-design
```

Or let Pi automatically route to it based on conversation context and need.
